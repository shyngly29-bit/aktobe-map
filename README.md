# Ақтөбе ескерткіштері

Интерактивная карта исторических памятников, мемориалов, храмов, музеев и улиц Актобе на казахском и русском языках. Проект к теме «Ақтөбе қаласының тарихи-мәдени ескерткіштері: тарихи жадыны сақтаудағы маңызы».

## Что умеет карта

- Светлая векторная карта центра Актобе в духе 2ГИС: названия улиц вдоль дорог видны сразу после загрузки, при приближении появляются второстепенные.
- 38 объектов в четырёх категориях: памятники, мемориалы, храмы и мечети, музеи. Близкие метки объединяются на общем плане.
- Карточка объекта: в левой панели на ПК и в нижней шторке на телефоне. Название, категория, улица, краткая справка, действия, изображение и вкладки «Қысқаша / Толығырақ».
- 18 улиц с историей: прежние названия с годами, личность, в честь которой названа улица, и голосовой рассказ.
- Маршрут «Ақтөбенің тарихи тұлғалары» из 8 остановок и режим прогулки.
- Ссылки на 3D-туры visitaktobe.kz и панорамы.
- Переключатель ҚАЗ / РУС, поиск по современным и прежним названиям.

## Как открыть

Онлайн: **https://shyngly29-bit.github.io/aktobe-map/**

Главный файл — `aktobe-pamyatniki-premium.html`. Его нужно открывать вместе с папкой `img/`, так как изображения подключаются по относительным путям.

Чтобы геолокация в режиме прогулки работала, страницу нужно открывать через `localhost` или HTTPS, например:

```bash
python -m http.server 8765
```

Затем откройте `http://localhost:8765/aktobe-pamyatniki-premium.html`.

## Структура

| Путь | Что там |
|---|---|
| `aktobe-pamyatniki-premium.html` | Готовая страница (текущая версия) |
| `aktobe-pamyatniki.html` | Первая версия карты |
| `img/` | Портреты и фото с Wikimedia Commons, `img/fig/` — фигуры и фоны в WebP |
| `figures/*.txt` | Описания фигур (сами PNG-оригиналы в репозиторий не входят) |
| `screenshots/` | Скриншоты открытой карточки на ПК и телефоне |
| `build/` | Данные и скрипты сборки |

## Сборка

Страница собирается цепочкой скриптов в `build/`:

```bash
cd build
python make_v4.py && python make_v4_js.py && python make_v5.py && python make_v6.py && python make_v7.py && python assemble_v7.py
```

Основные данные:

- `template.html` — список объектов, описания на двух языках, ссылки на 3D-туры;
- `streets.json` — улицы из OpenStreetMap (названия, прежние названия, геометрия);
- `stories.json` — истории улиц с источниками;
- `details.json` — краткие и подробные справки о личностях;
- `extra.json`, `credits.json` — подписи, контуры объектов и авторство изображений;
- `base2_svg.txt` — подложка карты (дороги, вода, парки).

Скрипты `build_streets.py`, `build_base.py`, `extra.py` и `fetch_images.py` пересобирают эти данные из OpenStreetMap и Wikimedia.

## Источники и лицензии

- Картографические данные: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL.
- Портреты и фото объектов: Wikimedia Commons, автор и лицензия указаны в карточке и в `build/credits.json`.
- Прежние названия улиц: OpenStreetMap и статья Википедии «Переименованные улицы Актобе».
- Ссылки на 3D-туры взяты с QR-кодов туристической карты «Aqtöbe altyn besigim» (visitaktobe.kz).
- Фигуры в полный рост в `img/fig/` — художественные реконструкции, а не архивные фотографии. На карте они подписаны «Көркем реконструкция / Художественная реконструкция».
